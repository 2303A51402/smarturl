API Documentation
RESTful endpoints — all return JSON. Full Swagger UI at /docs
POST /api/shorten
Shorten a URL with optional custom alias. Returns short code, AI title & category.
{ "url": "https://example.com", "custom_alias": "my-link" }
GET /api/urls
List all shortened URLs with click counts. Supports ?limit=20&skip=0
GET /api/stats/{short_code}
Per-URL analytics: total clicks, daily breakdown, hourly distribution.
GET /api/dashboard
Overall stats: total URLs, total clicks, category breakdown, top 5 URLs.
GET /{short_code}
Redirect to original URL and log the click (302 redirect).
DELETE /api/urls/{short_code}
Delete a shortened URL permanently.
